# SnipLite Plugin Catalog

SnipLite reads [catalog.json](https://gxdongv.github.io/SnipLite-Plugin-Catalog/catalog.json) to discover plugins. Entries identify the publisher, version, host and architecture requirements, HTTPS release asset, and SHA-256 digest.

Propose additions as pull requests after the independently versioned release is available. Match the package manifest and calculate the digest from the published asset.
