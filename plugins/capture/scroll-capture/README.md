0.1.20 会记住自动滚动开关。自动和手动长截图都会显示拼接进度，并避免截入控制面板的阴影。

0.1.15 在捕获完成后直接打开主程序的图像预览。SnipLite 0.3.19 提供新版窗口样式和图标工具栏。

0.1.13 将固定顶栏、左右侧栏和底栏分别保留在长图开头、首屏两侧和末尾。长图预览带有复制、保存和缩放图标。

- **SnipLite v0.3.17 及以上**。打开「首选项 → 插件 → 发现插件」，选择长截图进行安装或更新。也可在「已安装插件」中导入下载的安装包。
- **SnipLite v0.3.16**。下载 `.snipplugin`，然后打开「首选项 → 插件 → 导入插件」。

更新后重启 SnipLite。
