# 长截图（Scroll Capture）

自动或手动滚动选区，并拼接成长截图。由 GxDongV 维护。

| 版本 | SnipLite 版本 | 安装包 |
| --- | --- | --- |
| 0.1.7 | 0.3.16 及以上 | [下载 .snipplugin](https://github.com/GxDongV/SnipLite-Plugin-Catalog/releases/download/scroll-capture-v0.1.7/sniplite.scroll-capture-0.1.7.snipplugin) |

在 SnipLite 的「首选项 → 插件 → 发现插件」安装或更新。手动下载后，可在「已安装插件」中导入。更新后重启 SnipLite。

[版本发布页](https://github.com/GxDongV/SnipLite-Plugin-Catalog/releases/tag/scroll-capture-v0.1.7) · [插件源码](https://github.com/GxDongV/SnipLite-ScrollCapture)
