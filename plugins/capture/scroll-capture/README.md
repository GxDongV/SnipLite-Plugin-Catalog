# 长截图（Scroll Capture）

自动或手动滚动选区，并拼接成长截图。由 GxDongV 维护。

| 版本 | SnipLite 版本 | 安装包 |
| --- | --- | --- |
| 0.1.7 | 0.3.16 及以上 | [下载 .snipplugin](https://github.com/GxDongV/SnipLite-Plugin-Catalog/releases/download/scroll-capture-v0.1.7/sniplite.scroll-capture-0.1.7.snipplugin) |

0.1.7 是长截图首次独立发布的版本。SnipLite v0.3.17 随附长截图 0.1.6，可按下列方式升级。

- **SnipLite v0.3.17 及以上**。打开「首选项 → 插件 → 发现插件」，选择长截图进行安装或更新。也可在「已安装插件」中导入下载的安装包。
- **SnipLite v0.3.16**。下载 `.snipplugin`，然后打开「首选项 → 插件 → 导入插件」。

更新后重启 SnipLite。
