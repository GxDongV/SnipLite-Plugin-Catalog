# 屏幕录制

屏幕录制 0.5.12 支持 SnipLite 0.3.31 或更高版本的 Windows x64 主程序。

打开「首选项 → 插件 → 发现插件」，安装并启用「屏幕录制」。按 F1 框选，然后在截图工具栏的插件组点击「录制」。支持 MP4、GIF、APNG、动态 WebP，可暂停、继续或复制当前帧。
